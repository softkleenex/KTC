# 카카오 테크 캠퍼스 - 프리코스 과정

카카오 테크 캠퍼스 프리코스 과정에서 학습한 내용과 실습 코드를 정리한 저장소입니다.

## 구조

```text
.
├── notes/          # 주차별 학습 노트와 강의자료
├── code/           # 주차별 실습 코드
└── learning-log/   # 주차별 학습일지와 피드백
```

## 폴더 설명

| 폴더 | 설명 |
| --- | --- |
| `notes/` | 수업 내용을 주차/일차별로 정리한 Markdown 노트 |
| `code/` | Python, FastAPI, React, Next.js, Docker 실습 코드 |
| `learning-log/` | 매주 작성한 학습일지와 튜터 피드백 |

## 주차별 흐름

| 주차 | 주요 내용 |
| --- | --- |
| 1주차 | Python 심화, 비동기, HTTP/API, FastAPI, Pydantic, DB/SQL 기초 |
| 2주차 | SQL 조회/조작, FastAPI와 DB 연결, HTML/CSS, JavaScript 기초 |
| 3주차 | DOM, 이벤트, 비동기 JavaScript, React, Tailwind CSS, GitHub 협업 |
| 4주차 | Next.js App Router, Server Component, 풀스택 CRUD, 배포, E2E 검증 |
| 5주차 | Docker, Docker Compose, FastAPI/MySQL 컨테이너 구성, AWS RDS 연동 |

## 블로그 업로드 메모

블로그 글로 옮길 때는 `notes/블로그 업로드 점검.md`를 기준으로 이미지 링크, Obsidian 전용 문법, 강의자료 원문 의존도를 정리합니다.

## 보안 메모

- `.env`, DB 파일, 가상환경, 빌드 결과물은 저장소에 포함하지 않습니다.
- RDS endpoint, password, token 같은 민감정보는 블로그나 GitHub에 올리지 않습니다.
- 실습용 placeholder와 예시 계정은 실제 접속 정보가 아닙니다.
